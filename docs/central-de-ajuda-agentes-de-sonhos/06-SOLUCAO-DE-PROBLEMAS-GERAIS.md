# Solução de problemas gerais

## Não consigo fazer login
- Verifique se o e-mail está correto.
- Use Esqueci minha senha se precisar redefinir.
- Se aparecer mensagem de bloqueio temporário, aguarde alguns minutos antes de tentar novamente.

## Sou desconectado durante o uso
- A sessão expira após 20 minutos sem atividade. Movimente o mouse ou digite em um formulário para manter ativa.
- Se ocorrer em pouco tempo, verifique se há mais de uma aba aberta com a plataforma.

## Não vejo um módulo no menu
- Pode ser uma limitação do seu plano. Verifique em Planos quais recursos estão incluídos.
- Pode também ser uma permissão de equipe. Peça ao titular para revisar suas permissões.

## Um link público não abre
- Confirme se o link inclui o domínio correto (`carteiradigital.tur.br`, `seuorcamento.tur.br`, `seuroteiro.tur.br` ou `contato.tur.br`).
- Verifique se a carteira/orçamento/roteiro continua publicado e ativo.
- Se o conteúdo tiver senha, confirme com o cliente que ele está usando a senha correta.

## Subi um documento e a IA não preencheu corretamente
- A IA é uma ajuda inicial; sempre revise os dados antes de salvar.
- Use documentos legíveis e completos (sem corte).

## Quando procurar o suporte
Quando o problema persistir após as orientações acima, abra um chamado em Suporte com:
- Descrição do problema;
- Passo a passo do que você fez;
- Capturas de tela;
- Data e horário aproximado.
