# Filtrar o dashboard por período

## O que você fará
Os números refletem apenas o período selecionado.

## Passo a passo
1. Abra **Financeiro → Visão Geral**.
2. Localize o seletor de período no topo.
3. Escolha o mês ou intervalo desejado.
4. Os indicadores e tabelas se atualizam.

## Resultado esperado
Os números refletem apenas o período selecionado.
