# Navegar entre as abas do Financeiro

## O que você fará
Você localiza qualquer submódulo a partir do mesmo ponto de partida.

## Passo a passo
1. Use as abas primárias (Visão Geral, Vendas, Entradas, Despesas, Comissões).
2. Clique em **Mais** para acessar Vendedores, Faturas e Fornecedores.
3. A URL é atualizada automaticamente para a aba ativa.

## Resultado esperado
Você localiza qualquer submódulo a partir do mesmo ponto de partida.
