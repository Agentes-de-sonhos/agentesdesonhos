# Perguntas frequentes — Financeiro

Perguntas canônicas validadas a partir da Base de Conhecimento Mestre.

## Como registrar uma nova venda?

**Pergunta:** Como registrar uma nova venda?

**O que o usuário pode perguntar:**
- Como lanço uma venda?
- Onde registro fechamento?

**Resposta direta:** Acesse Financeiro → Vendas → Nova venda. O wizard pede cliente, vendedor, produto/serviço, valor, comissões e termos.

**Pré-requisitos:** Ter acesso ao módulo Financeiro com permissão suficiente.

**Quem pode fazer:** titular, financeiro.

**Plano ou permissão necessária:** todos.

**Status da resposta:** pronto.

**Nível de confiança:** confirmado.

**ID:** `financeiro-faq-01`
