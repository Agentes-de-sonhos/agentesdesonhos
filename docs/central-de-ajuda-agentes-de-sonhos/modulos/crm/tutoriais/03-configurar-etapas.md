# Como configurar as etapas do funil

## O que você fará
Criar, renomear, reordenar e excluir etapas do funil de oportunidades.

## Antes de começar
- Ser titular ou ter permissão de gestão do CRM.

## Passo a passo
1. Acesse o CRM.
2. No fim das colunas do Kanban, use **Adicionar etapa** para criar uma nova coluna.
3. Para renomear, abra o cabeçalho da coluna e edite o nome.
4. Para reordenar, arraste as colunas até a posição desejada.
5. Para excluir, abra o cabeçalho da coluna e selecione **Excluir etapa**. Mova as oportunidades antes, se houver.

## Resultado esperado
O funil reflete imediatamente as etapas configuradas para a agência.

## Atenção
Excluir uma etapa pode exigir realocação das oportunidades existentes nela.
