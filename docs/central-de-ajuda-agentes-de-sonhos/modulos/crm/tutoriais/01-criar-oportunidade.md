# Como criar uma oportunidade do zero

## O que você fará
Criar a primeira oportunidade no funil do CRM, vinculada a um cliente.

## Antes de começar
- Tenha um cliente cadastrado (ou esteja preparado para cadastrar na hora).
- Confirme que seu perfil tem permissão para criar oportunidades.

## Passo a passo
1. Acesse o menu **CRM** (ou **Clientes → Oportunidades**).
2. Clique em **Nova oportunidade**.
3. Busque o cliente ou use **Adicionar cliente** para cadastrá-lo rapidamente.
4. Preencha título/destino, etapa inicial, valor estimado (opcional) e data prevista de viagem (opcional).
5. Aplique etiquetas e atribua um responsável, se necessário.
6. Clique em **Salvar**. A oportunidade aparece na primeira etapa do Kanban.

## Resultado esperado
Um novo card visível no Kanban, na etapa selecionada, com o cliente vinculado.

## Atenção
O cliente é obrigatório. Sem ele a oportunidade não é salva.
