# Use etiquetas com critério

## Por que importa
Etiquetas mal definidas perdem utilidade rapidamente. Critérios claros transformam etiquetas em filtros poderosos.

## Recomendações
- Defina categorias fixas: origem do lead, prioridade, tipo de viagem.
- Limite a quantidade total de etiquetas para evitar inflação.
- Use cores para distinguir famílias de etiquetas.
- Revise e arquive etiquetas obsoletas periodicamente.

## Como aplicar
1. Crie um padrão escrito de etiquetas.
2. Treine a equipe.
3. Audite mensalmente. Use [Gerenciar etiquetas](../tutoriais/04-gerenciar-etiquetas.md).
