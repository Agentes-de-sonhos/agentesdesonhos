# Padronize o cadastro de clientes no CRM

## Por que importa
Cadastros uniformes evitam duplicidades, melhoram buscas e tornam relatórios confiáveis.

## Recomendações
- Defina campos mínimos obrigatórios (nome completo, telefone, e-mail).
- Antes de criar um cliente, pesquise se já existe.
- Use o cadastro rápido apenas quando necessário e complemente depois.
- Mantenha o titular como referência única para definir o padrão.

## Como aplicar
1. Documente o padrão para a equipe.
2. Use o tutorial [Importar contatos](../tutoriais/06-importar-contatos.md) ao subir bases iniciais.
