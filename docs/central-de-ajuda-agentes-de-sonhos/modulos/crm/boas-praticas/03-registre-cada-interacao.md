# Registre cada interação com o cliente

## Por que importa
O histórico completo na oportunidade evita perda de contexto quando a negociação muda de mãos ou se prolonga.

## Recomendações
- Após cada contato, registre uma nota objetiva.
- Crie um follow-up para o próximo passo.
- Marque follow-ups como concluídos quando realizados.
- Evite registrar dados sensíveis desnecessários.

## Como aplicar
1. Adote a rotina ao final de cada contato.
2. Padronize um modelo curto de nota (data, canal, próxima ação).
