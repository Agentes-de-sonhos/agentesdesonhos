# Filtrar comissões por mês

## O que você fará
A lista mostra apenas as comissões com data esperada no período selecionado.

## Antes de começar
- Estar logado com perfil **Titular** ou **Financeiro**.
- Ter acesso ao módulo **Comissões e Vendedores**.

## Passo a passo
1. Em **Financeiro**, use o seletor de **mês** no topo.
2. Abra a aba **Comissões**.
3. Confirme que a lista foi atualizada.
4. Use filtros adicionais (fornecedor, status) se desejar refinar.

## Resultado esperado
A lista mostra apenas as comissões com data esperada no período selecionado.

## Atenção
Confirme as ações antes de salvar — alterações financeiras impactam relatórios e indicadores do mês.
