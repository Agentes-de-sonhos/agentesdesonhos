# Acompanhar comissões atrasadas

## O que você fará
Você identifica rapidamente comissões com data esperada vencida.

## Antes de começar
- Estar logado com perfil **Titular** ou **Financeiro**.
- Ter acesso ao módulo **Comissões e Vendedores**.

## Passo a passo
1. Abra **Financeiro → Comissões → Comissões**.
2. Procure pelo indicador/coluna **Atrasada** na lista.
3. Abra cada item para verificar fornecedor, data esperada e venda de origem.
4. Entre em contato com o fornecedor para alinhar o recebimento.

## Resultado esperado
Você identifica rapidamente comissões com data esperada vencida.

## Atenção
Confirme as ações antes de salvar — alterações financeiras impactam relatórios e indicadores do mês.
