# Criar uma nova operação

## O que você fará
Abrir uma operação para acompanhar o pós-venda de uma viagem específica.

## Antes de começar
- O cliente já deve estar cadastrado em Gestão de Clientes.
- Tenha pelo menos uma tarefa em mente — o sistema exige no mínimo uma para salvar.

## Passo a passo
1. Acesse **Gestão de Clientes › Operações**.
2. Clique em **Nova Operação**.
3. No campo **Cliente**, selecione **"Selecione um cliente"** e escolha o cliente.
4. Informe um título descritivo (ex: "Lua de mel Maldivas").
5. Adicione tarefas iniciais usando **Adicionar tarefa...**.
6. Clique em **Criar**.

## Resultado esperado
O toast **"Operação criada"** confirma a ação. O card aparece na coluna inicial do quadro.

## Atenção
Se aparecer **"Adicione ao menos uma tarefa antes de salvar."**, inclua pelo menos uma tarefa antes de tentar salvar novamente.
