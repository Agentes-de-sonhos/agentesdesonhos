# Salvar um checklist como padrão para uma etapa

## O que você fará
Criar um conjunto reutilizável de tarefas para que novas operações em determinada etapa já comecem com o checklist correto.

## Passo a passo
1. Abra uma operação que esteja na etapa desejada.
2. Monte a lista de tarefas que devem virar padrão.
3. Use a opção de salvar checklist como padrão para a etapa.

## Resultado esperado
Aparece a mensagem **"Checklist salvo como padrão para esta etapa."**. Novas operações que entrarem nessa etapa já recebem essas tarefas.

## Atenção
Se você remover o modelo personalizado, verá **"Modelo personalizado removido. Novas operações usarão o checklist sugerido."**.
