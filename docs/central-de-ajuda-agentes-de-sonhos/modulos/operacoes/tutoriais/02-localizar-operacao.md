# Localizar uma operação no quadro

## O que você fará
Encontrar rapidamente uma operação específica entre todas as do quadro.

## Passo a passo
1. Acesse **Gestão de Clientes › Operações**.
2. Clique no campo **Buscar operações...**.
3. Digite parte do título ou nome do cliente.

## Resultado esperado
O quadro destaca apenas as operações que correspondem ao termo digitado.
