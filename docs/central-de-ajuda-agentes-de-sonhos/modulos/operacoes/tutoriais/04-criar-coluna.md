# Criar uma nova coluna (etapa) no quadro de Operações

## O que você fará
Adicionar uma etapa ao quadro de operações para refletir um passo específico do seu processo.

## Passo a passo
1. Acesse **Gestão de Clientes › Operações**.
2. Use a ação de adicionar nova coluna ao final do quadro.
3. No campo **Nome da nova coluna**, digite o nome.
4. Confirme.

## Resultado esperado
A nova coluna aparece no quadro e está pronta para receber operações.

## Atenção
Mudanças no pipeline afetam todos os usuários da agência. Combine com a equipe antes de alterar.
