# Adicionar tarefas a uma operação

## O que você fará
Registrar atividades operacionais (ex: emitir voucher, confirmar transfer).

## Passo a passo
1. Abra a operação clicando no card.
2. Localize o campo **Adicionar tarefa...**.
3. Digite o título da tarefa.
4. Pressione **Enter** para incluir.
5. Repita para cada nova tarefa.

## Resultado esperado
As tarefas aparecem na lista da operação e podem ser concluídas conforme o atendimento avança.
