# Mover uma operação entre etapas

## O que você fará
Atualizar o estágio de uma operação conforme o andamento do atendimento.

## Passo a passo
1. Abra **Gestão de Clientes › Operações**.
2. Clique e segure o card da operação.
3. Arraste até a coluna da nova etapa.
4. Solte o card.

## Resultado esperado
Aparece o toast **"Etapa alterada"**. A mudança fica registrada no histórico.

## Atenção
Se nada acontecer ao soltar, verifique se você tem permissão de edição. Veja o artigo de [problema com movimentação](../problemas-comuns/02-operacao-nao-pode-ser-movida.md).
