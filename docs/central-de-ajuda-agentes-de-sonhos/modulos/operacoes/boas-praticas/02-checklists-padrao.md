# Use checklists padrão para cada etapa

## Por que importa
Checklists padronizam o atendimento, reduzem esquecimentos e aceleram a integração de novos membros.

## Como aplicar no Agentes de Sonhos
1. Para cada etapa do pipeline, monte uma lista de tarefas essenciais.
2. Salve-a como **checklist padrão para esta etapa**.
3. Revise periodicamente para refletir mudanças no processo.

## Erros que evita
- Tarefas operacionais esquecidas.
- Atendimentos com qualidade desigual entre membros da equipe.
