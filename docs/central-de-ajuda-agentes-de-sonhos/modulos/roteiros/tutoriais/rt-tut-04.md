# Reordenar atividades dentro de um período

## O que você fará
A ordem é persistida automaticamente e refletida no link público.

## Passo a passo
1. Abra o roteiro no dia desejado.
2. Arraste a atividade segurando o controle lateral.
3. Solte na nova posição.
4. A plataforma confirma com **Atividade movida**.

## Resultado esperado
A ordem é persistida automaticamente e refletida no link público.
