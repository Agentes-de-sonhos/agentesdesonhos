# Compartilhar o link público do roteiro

## O que você fará
O cliente acessa o roteiro pela web sem precisar de login.

## Passo a passo
1. Abra o roteiro pronto.
2. Clique em **Compartilhar**.
3. Confirme a mensagem **Link copiado! O roteiro foi publicado.**
4. Envie o link ao cliente no canal preferido.

## Resultado esperado
O cliente acessa o roteiro pela web sem precisar de login.
