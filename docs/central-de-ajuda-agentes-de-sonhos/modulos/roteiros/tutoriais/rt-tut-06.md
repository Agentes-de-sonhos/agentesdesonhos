# Usar um modelo de roteiro como ponto de partida

## O que você fará
Um novo roteiro editável é criado a partir do modelo.

## Passo a passo
1. Acesse **Ferramentas IA → Modelos de Roteiros**.
2. Abra o modelo desejado.
3. Clique em **Clonar** (ou opção equivalente).
4. Ajuste destino, datas e atividades conforme o cliente.

## Resultado esperado
Um novo roteiro editável é criado a partir do modelo.
