# Alterações no roteiro não aparecem no link público

## Sintoma
O cliente vê uma versão antiga do roteiro.

## Causas possíveis
- Cache do navegador do cliente.
- Roteiro não foi republicado.

## Solução passo a passo
1. Peça ao cliente para recarregar a página (Ctrl+F5).
2. Republique pelo botão **Compartilhar**.

## Quando procurar o suporte
Se o problema persistir após os passos acima, abra um ticket informando o módulo, o horário e o comportamento observado. Não compartilhe senhas.
