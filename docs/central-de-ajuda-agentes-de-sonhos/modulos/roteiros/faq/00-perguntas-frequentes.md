# Perguntas frequentes — Roteiros

Perguntas canônicas validadas com base na Base de Conhecimento Mestre e na interface atual (`/ferramentas-ia/criar-roteiro`).

## Onde encontro o módulo Roteiros?

**Pergunta:** Onde encontro o módulo Roteiros?

**O que o usuário pode perguntar:**
- onde fica roteiros
- como acessar roteiros

**Resposta direta:** No menu principal, em **Ferramentas IA → Criar Roteiro** (caminho `/ferramentas-ia/criar-roteiro`).

**Pré-requisitos:** Ter acesso ao módulo correspondente com permissão suficiente.

**Status da resposta:** pronto.

**Nível de confiança:** confirmado.

**ID:** `rt-faq-21`

## Como crio um roteiro novo?

**Pré-requisitos:** Ter acesso ao módulo correspondente com permissão suficiente.
