# Proteger a carteira com senha

## O que você fará
Exigir uma senha para acesso público à carteira.

## Passo a passo
1. Abra a carteira em edição.
2. Ative a opção **Proteger com senha**.
3. Defina uma senha forte.
4. Salve a carteira.
5. Envie a senha ao cliente por canal seguro.

## Resultado esperado
O cliente precisa digitar a senha para visualizar o conteúdo público.

## Atenção
Após 3 tentativas inválidas o acesso fica bloqueado temporariamente.
