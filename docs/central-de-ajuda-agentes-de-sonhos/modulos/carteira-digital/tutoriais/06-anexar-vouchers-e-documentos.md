# Anexar vouchers e documentos

## O que você fará
Adicionar PDFs, imagens e comprovantes a um serviço da carteira.

## Passo a passo
1. Abra o serviço em edição.
2. Use a área de **Anexos** para enviar PDFs ou imagens.
3. Aguarde o upload concluir.
4. Salve o serviço.

## Resultado esperado
O cliente acessa os documentos via URL assinada no link público.

## Atenção
Os arquivos são servidos via proxy seguro, não ficam expostos publicamente sem autorização.
