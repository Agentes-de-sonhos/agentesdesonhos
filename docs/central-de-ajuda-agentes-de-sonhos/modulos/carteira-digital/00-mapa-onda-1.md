## Tutoriais planejados
- Criar uma carteira para uma viagem
- Adicionar serviços por categoria
- Anexar vouchers
- Compartilhar o link da carteira
- Definir senha de acesso
- Instalar a carteira como aplicativo
- Atualizar próximos serviços
- Editar identidade visual da carteira

## Problemas comuns planejados
- Cliente não consegue abrir a carteira
- Voucher não abre no link público
- Senha foi bloqueada por tentativas
- Próximo serviço não atualiza
- Identidade visual não reflete a marca da agência

## Boas práticas planejadas
- Padronize categorias de serviços
- Use sempre cliente vinculado
- Confirme a versão pública atual antes de compartilhar
- Cuide do uso de senhas para evitar bloqueios
