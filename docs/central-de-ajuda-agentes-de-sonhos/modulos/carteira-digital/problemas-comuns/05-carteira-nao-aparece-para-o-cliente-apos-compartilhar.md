# Carteira não aparece para o cliente após compartilhar

## Sintoma
O cliente diz que o link não exibe nenhum conteúdo.

## Causas possíveis
- Carteira foi salva sem serviços.
- Slug da agência foi alterado.
- Cliente está usando link antigo.

## Como verificar
1. Reabra a carteira e confira a lista de serviços.
2. Copie novamente o link em **Compartilhar**.

## Solução passo a passo
1. Adicione pelo menos um serviço, se a lista estiver vazia.
2. Reenvie o link atualizado ao cliente.
3. Peça para o cliente abrir em aba anônima.

## Quando procurar suporte
Se o problema persistir mesmo com serviços visíveis no painel, contate o suporte informando o ID da carteira.
