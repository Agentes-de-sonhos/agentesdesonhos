# Importar uma venda a partir de uma oportunidade do CRM

## O que você fará
Você cria uma venda já preenchida com cliente e destino vindos de uma oportunidade fechada.

## Antes de começar
- Estar logado com perfil **Titular** ou **Financeiro**.
- Ter acesso ao módulo **Vendas**.

## Passo a passo
1. Acesse **Financeiro → Vendas → Nova Venda**.
2. Na etapa **Origem**, escolha **A partir do CRM**.
3. Selecione a oportunidade no seletor de oportunidades fechadas.
4. Confirme cliente e dados pré-preenchidos.
5. Complete os produtos da venda.
6. Salve para concluir o registro.

## Resultado esperado
Você cria uma venda já preenchida com cliente e destino vindos de uma oportunidade fechada.

## Atenção
Confirme as ações antes de salvar — alterações financeiras impactam relatórios e indicadores do mês.
