# Vincular um cliente a uma oportunidade

## O que você fará
Associar um cliente existente (ou recém-criado) a uma oportunidade comercial no CRM.

## Passo a passo
1. Acesse o CRM e clique em **Nova Oportunidade**.
2. No campo de cliente, selecione o cliente desejado.
3. Caso ele ainda não exista, clique em **Novo Contato** para criar pelo cadastro rápido.
4. Complete os demais dados da oportunidade e salve.

## Resultado esperado
A oportunidade aparece vinculada ao cliente. Você pode visualizá-la também no perfil do cliente em Gestão de Clientes.
