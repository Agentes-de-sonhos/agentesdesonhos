# Editar dados de um cliente

## O que você fará
Atualizar nome, contato, observações ou preferências de um cliente já cadastrado.

## Antes de começar
- Saiba quais campos serão atualizados.
- Verifique se você tem permissão de edição.

## Passo a passo
1. Vá em **Gestão de Clientes › Clientes**.
2. Use **Buscar clientes...** para localizar o cliente.
3. Clique em **Abrir Cliente**.
4. Clique em **Editar Cliente**.
5. Atualize os campos desejados.
6. Clique em **Salvar alterações**.

## Resultado esperado
Os dados aparecem atualizados imediatamente na lista e nos módulos vinculados.
