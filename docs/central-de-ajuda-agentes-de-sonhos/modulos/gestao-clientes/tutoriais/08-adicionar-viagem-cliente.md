# Adicionar uma viagem ao cliente

## O que você fará
Registrar uma nova viagem associada a um cliente para uso em roteiros, orçamentos e carteira digital.

## Passo a passo
1. Abra o cliente em **Gestão de Clientes › Clientes**.
2. Clique em **Adicionar Viagem**.
3. Preencha o destino (ex: "Paris, França").
4. Informe as datas e demais detalhes.
5. Clique em **Salvar**.

## Resultado esperado
A viagem fica listada no perfil do cliente. O mesmo cliente pode ter várias viagens vinculadas.
