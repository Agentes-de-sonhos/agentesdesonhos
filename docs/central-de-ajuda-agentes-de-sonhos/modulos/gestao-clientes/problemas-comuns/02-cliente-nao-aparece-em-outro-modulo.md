# Cliente não aparece no seletor de outro módulo

## Sintoma
Ao criar uma oportunidade, orçamento, roteiro ou carteira digital, o cliente não aparece no campo **Selecione um cliente**.

## Causas possíveis
- O cliente ainda não foi cadastrado.
- O cadastro foi feito com nome diferente.
- O membro da equipe não tem permissão para visualizar aquele cliente.

## Como verificar
1. Abra **Gestão de Clientes › Clientes** e confirme se o cliente existe.
2. Verifique a grafia exata do nome.
3. Confirme se o membro tem permissão de acesso a Gestão de Clientes.

## Solução passo a passo
1. Se não existir, crie pelo botão **Novo Cliente** ou pelo **Novo Contato** (cadastro rápido).
2. Recarregue a tela do módulo de destino e tente selecionar novamente.

## Quando procurar suporte
Se mesmo após o cadastro o cliente não aparecer em outros módulos, registre um chamado com o nome e a data da criação.
