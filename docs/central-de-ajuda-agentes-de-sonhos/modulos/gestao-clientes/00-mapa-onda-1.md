## Tutoriais planejados
- Cadastrar um cliente
- Editar dados de um cliente
- Excluir um cliente
- Importar uma lista de clientes
- Buscar e filtrar clientes
- Anexar documentos a um cliente
- Vincular um cliente a uma oportunidade
- Diferenciar cliente e passageiro

## Problemas comuns planejados
- Cliente duplicado no cadastro
- Não consigo excluir um cliente vinculado
- Importação de clientes com erros
- Documento do cliente não abre
- Membro da equipe não vê todos os clientes

## Boas práticas planejadas
- Padronize campos mínimos de cadastro
- Evite duplicidades antes de salvar
- Mantenha histórico de viagens atualizado
- Separe cliente comprador de passageiros
