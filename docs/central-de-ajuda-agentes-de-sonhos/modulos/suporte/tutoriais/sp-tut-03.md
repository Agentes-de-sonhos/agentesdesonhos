# Anexar um print no chamado

## O que você fará
A imagem é enviada e aparece direto na conversa.

## Antes de começar
- Já ter o print salvo no dispositivo.
- Garantir que o print não exposse senhas ou dados de cartão.

## Passo a passo
1. Abra o chamado no qual deseja anexar.
2. Clique no ícone de **clipe** (📎) no rodapé da conversa.
3. Selecione a imagem (JPG, PNG, etc.).
4. Escreva uma mensagem curta explicando o print.
5. Clique em enviar.

## Resultado esperado
O print aparece embutido na conversa para o suporte visualizar.
