# Compartilhar o link público do orçamento

## O que você fará
Enviar o orçamento ao cliente por WhatsApp, e-mail ou outro canal.

## Passo a passo
1. Abra o orçamento.
2. Clique em **Compartilhar**.
3. Use **Copiar link** para copiar a URL pública.
4. Cole o link no WhatsApp, e-mail ou no canal desejado.

## Resultado esperado
O cliente acessa o orçamento direto pelo navegador, sem login.

## Atenção
O link reflete edições em tempo real — qualquer alteração no orçamento aparece imediatamente para quem acessar.
