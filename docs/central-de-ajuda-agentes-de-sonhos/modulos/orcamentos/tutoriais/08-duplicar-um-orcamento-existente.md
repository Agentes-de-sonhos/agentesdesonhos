# Duplicar um orçamento existente

## O que você fará
Reaproveitar um orçamento anterior como base para uma nova proposta.

## Passo a passo
1. Abra o orçamento desejado.
2. Clique em **Duplicar**.
3. Edite os campos que precisam mudar (cliente, datas, valores).
4. Salve o novo orçamento.

## Resultado esperado
Um novo orçamento é criado em modo edição com os serviços copiados.

## Atenção
A duplicação não copia o histórico de visualizações nem o link público antigo.
