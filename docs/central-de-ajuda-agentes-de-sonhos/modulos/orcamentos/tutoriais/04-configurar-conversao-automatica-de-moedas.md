# Configurar conversão automática de moedas

## O que você fará
Definir taxa de câmbio do orçamento para converter valores informados em outras moedas.

## Passo a passo
1. Abra o orçamento.
2. No cabeçalho, escolha modo **Conversão Automática**.
3. Informe a **Taxa de câmbio** desejada.
4. Adicione serviços com valores em moeda estrangeira.
5. Confirme que os totais foram convertidos para a moeda do orçamento.

## Resultado esperado
Os valores aparecem convertidos para o cliente no link público.

## Atenção
Use o modo **Fixo** quando o pagamento será efetivamente feito em moeda estrangeira.
