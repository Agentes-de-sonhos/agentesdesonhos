# Perguntas frequentes — Orçamentos

Perguntas canônicas validadas a partir da Base de Conhecimento Mestre.

## Como criar um novo orçamento?

**Pergunta:** Como criar um novo orçamento?

**O que o usuário pode perguntar:**
- Como faço uma proposta?
- Onde gero cotação?

**Resposta direta:** Acesse Criar → Orçamento, selecione o cliente, defina a moeda (BRL, USD ou EUR) e adicione os serviços. Ao salvar, o link público fica disponível em seuorcamento.tur.br.

**Pré-requisitos:** Ter acesso ao módulo Orçamentos com permissão suficiente.

**Quem pode fazer:** agente, titular.

**Plano ou permissão necessária:** todos.

**Status da resposta:** pronto.

**Nível de confiança:** confirmado.

**ID:** `orcamentos-faq-01`
