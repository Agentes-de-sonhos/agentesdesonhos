# Vincule eventos a clientes ou oportunidades sempre que possível

## Por que importa
Vincular o evento facilita o follow-up e mantém o histórico do cliente completo.

## Como aplicar
1. Antes de criar o evento, decida se ele é comercial.
2. Use o **CRM** para criar follow-ups que aparecem na agenda.
3. Use **Descrição** para registrar a oportunidade relacionada.

## Evita
- Tarefas comerciais soltas.
- Dificuldade de auditoria.
