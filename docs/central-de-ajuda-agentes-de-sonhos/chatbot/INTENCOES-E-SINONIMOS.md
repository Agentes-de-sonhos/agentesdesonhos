# Intenções e sinônimos

Mapa para enriquecer a busca semântica. Os sinônimos devem ser tratados como variações da mesma intenção.

| Termo oficial | Sinônimos / como o usuário costuma falar |
|---|---|
| Cliente | Contato, comprador, contratante |
| Lead | Interessado, prospect, contato cru |
| Oportunidade | Negociação, deal, negócio, lead qualificado |
| Orçamento | Cotação, proposta, orçamento de viagem |
| Roteiro | Itinerário, programação, plano de viagem |
| Carteira Digital | Wallet, app da viagem, carteira do viajante |
| Viagem | Reserva, pacote, trip |
| Serviço | Item, produto da viagem |
| Passageiro | Viajante, hóspede |
| Venda | Fechamento, contrato fechado |
| Entrada | Recebimento, conta a receber |
| Despesa | Conta a pagar, gasto |
| Fatura | Invoice, boleto |
| Comissão | Honorário, repasse |
| Operação | Pós-venda, gestão da viagem |
| Vitrine | Showcase, página de ofertas |
| Cartão de Visitas | Cartão digital, business card |
| Lâminas | Flyers, peças promocionais |
