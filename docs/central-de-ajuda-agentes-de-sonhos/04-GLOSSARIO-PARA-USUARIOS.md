# Glossário para usuários

| Termo | Significado |
|---|---|
| Agência | A conta da empresa dentro do Agentes de Sonhos. |
| Agente | Usuário titular ou colaborador autorizado da agência. |
| Cliente | Pessoa cadastrada que contrata as viagens. |
| Passageiro | Pessoa que efetivamente viaja, vinculada a uma viagem. |
| Lead | Interessado captado em formulário, landing page ou indicação. |
| Oportunidade | Negociação registrada no funil do CRM. |
| Etapa do funil | Cada coluna do Kanban do CRM (configurável). |
| Orçamento | Proposta comercial enviada ao cliente. |
| Roteiro | Programação dia a dia da viagem. |
| Carteira Digital | App-like com todos os dados da viagem para o viajante. |
| Viagem | Registro operacional da viagem. |
| Serviço | Item da viagem (aéreo, hospedagem, transfer, passeio, ingresso, seguro, locação). |
| Venda | Registro financeiro do fechamento. |
| Entrada | Recebimento previsto ou realizado. |
| Despesa | Pagamento previsto ou realizado, inclusive comissões. |
| Fatura | Documento financeiro do cliente com parcelas. |
| Comissão | Valor recebido pela agência ou pago ao vendedor pela intermediação. |
| Operação | Acompanhamento pós-venda com tarefas e checklist. |
| Vitrine | Página pública com ofertas da agência. |
| Cartão de Visitas | Cartão digital com QR Code e link público. |
| Lâminas | Imagens promocionais geradas no Personalizador. |
| Plano Start / Profissional / Premium | Faixas de assinatura da plataforma. |

Outros termos específicos aparecem nos artigos do módulo correspondente.
